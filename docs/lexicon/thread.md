# Thread

- **Tags:** gameplay, design
- **Status:** ✅ (2026-10-04)
- **Journal:** unlocks in Opposites, the first level that weaves a single thread; page on the Loom tab
- **Also called:** row (across), column (down); weft and warp (the loom's words)

## Gameplay

A thread is one line of stitches in a cloth: a row across, or a column down. Some levels weave a single thread instead of a whole picture.

## Design

- Across: one row, the weft, woven left to right in one pass of the shuttle. Down: one column, a warp thread (DESIGN.md §4).
- Thread levels (Opposites, Turn the Wheel) weave one row of 8 stitches, every paint once in journal order, so the cloth reads as a lookup row: each paint beside what it becomes.
- No longer the word for what joins pieces: that's a [tube](tube.md).

## Implementation

No type of its own: a thread level is a level whose target picture is one row.
